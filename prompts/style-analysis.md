# Prompt: Reference PPT Style Analysis

Use this prompt after providing or describing a reference PowerPoint deck.

```text
Analyze this reference PowerPoint as a visual style source for a new presentation.

Please inspect:
- slide count and structure
- cover, contents, divider, body, and closing slide patterns
- color palette
- typography hierarchy
- layout rhythm
- image treatment
- background style
- recurring shapes, panels, lines, footers, and page numbers
- strengths worth preserving
- weaknesses to avoid

Return a concise style audit. Do not design the new deck yet.
```
