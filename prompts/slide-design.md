# Prompt: Slide Design And Build

Use this prompt after the slide outline has been approved.

```text
Build the approved presentation as an editable PowerPoint deck.

Requirements:
- Preserve the confirmed reference style direction.
- Use editable text boxes, shapes, callouts, timelines, cards, and image layers whenever possible.
- Avoid turning every slide into a flat screenshot.
- Use varied layouts so no three consecutive slides feel identical.
- Keep body text readable and uncrowded.
- Use verified real images for real people, books, companies, places, products, logos, screenshots, and covers.
- Use generated images only for non-identity atmosphere or abstract backgrounds.
- Record factual and image sources.

Before final delivery, render or preview the deck and perform visual QA.
```
