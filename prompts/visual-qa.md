# Prompt: Visual QA

Use this prompt after the deck has been built and rendered or previewed.

```text
Review this PowerPoint deck visually before delivery.

Check every slide for:
- thumbnail readability
- full-size readability
- title hierarchy
- body text spacing
- image crop quality
- color contrast
- text overlap
- clipping
- spelling mistakes
- repeated layouts
- fake logos, fake book covers, fake screenshots, or fake identity images

List concrete issues by slide number. If there are no issues, say so clearly and mention any residual risk.
```
