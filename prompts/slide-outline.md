# Prompt: Slide Outline

Use this prompt after the visual direction is confirmed.

```text
Create a slide-by-slide outline for the new presentation.

Topic: [topic]
Audience: [audience]
Language: [language]
Target slide count: [slide count]
Reference style summary: [style audit]
Visual direction: [confirmed direction]

For each slide, include:
- slide number
- title
- subtitle, if useful
- body copy
- visual suggestion
- highlight phrase or callout

Write the content first. Do not generate the final PPT until I confirm the outline.
```
